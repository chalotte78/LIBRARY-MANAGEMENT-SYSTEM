# LIBRARY-MANAGEMENT-SYSTEM
Based on the knowledge from the Object-Oriented Programming course, the Library Management System project was developed to combine theory with practice and create a practical application to help manage libraries effectively. This system is built using the Java programming language, with a simple command-line interface, and focuses on basic but essential functions. With three main roles: Administrator, Librarian, and Reader, the system provides functions for managing users, managing books, and handling book borrowing and returning.

Besides applying core principles of Object-Oriented Programming such as inheritance, polymorphism, encapsulation, and abstraction, the system also uses file handling to store data permanently. This not only helps ensure the system’s durability but also gives students the chance to practice concepts like file structure and exception handling in Java. The project is not only an exercise to apply knowledge but also simulates a real working process, helping students better understand how management systems are designed and operated.
